# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/frakment/mcp/security/advisories/new).

## Scope

The MCP server and package code in this repository are in scope.

The server returns registry content as data and does not execute shell commands or write files into a project.

Vulnerabilities in third-party dependencies should be reported to their respective maintainers.

Security fixes are provided for the latest published version of `@frakment/mcp`.
